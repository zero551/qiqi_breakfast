# 🍳 奇奇的早餐

给全家用的早餐老虎机。拉一下，帮你决定今天早上吃什么。

## 功能
- 🎰 **老虎机抽选**：只有标记「想吃」的早餐会进老虎机，3D 拉杆 → 减速 → 停在一个结果，带撒花
- 👆 **手动微调**：抽完可上下拨动滚轮，松手自动吸附，中间那格就是最终选择
- 🔄 **不满意再抽**：抽完可以「再来一次」
- ⚙️ **早餐管理**：内置主流中西式早餐，可自己添加 / 删除 / 开关「想吃」
- 📅 **自带日历**：月历视图 + 列表切换，每天吃了什么一目了然（同一天自动只保留最后一次）
- 👨‍👩‍👦 **全家共享**（云端模式）：所有人看到同一份列表和日历，谁改了大家都同步
- 📱 **手机即用**：浏览器打开，可「添加到主屏幕」，像 App 一样全屏使用

## 两种数据模式
| 模式 | 触发条件 | 数据存哪 | 适合 |
|------|----------|----------|------|
| 📱 本机模式 | 没有配置 Redis 环境变量 | 各自浏览器 localStorage | 本地试玩 |
| ☁️ 云端模式 | 配置了 Upstash Redis | Upstash Redis（全家共享） | 正式使用 |

代码会根据环境变量**自动切换**，前端无需任何改动。

## 本地开发
先安装依赖，再启动开发服务器：

    npm install
    npm run dev

然后打开 http://localhost:3000 。
本地开发若不填 .env.local 里的 Redis 变量，自动走本机模式，功能完整可玩。
